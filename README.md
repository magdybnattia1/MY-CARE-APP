# MY CARE

تطبيق Android عربي لمتابعة الرحلة العلاجية دون حساب أو اتصال بالإنترنت.

## الحالة الحالية
هذه أول نسخة تأسيسية للمشروع (MVP): تسجيل المواعيد والأعراض والأدوية والجلسات محليًا، مع تنبيه للمواعيد قبلها بيوم، وواجهة عربية RTL. هذه النسخة ليست إصدارًا طبيًا نهائيًا ولا ينبغي إدخال بيانات صحية حقيقية قبل استكمال التشفير واختبارات الأمان والنسخ الاحتياطي.

## البناء
يتم بناء APK تلقائيًا عبر GitHub Actions عند كل push إلى main. افتح تبويب Actions ثم نزّل artifact باسم MyCare-debug-apk بعد نجاح البناء.

## المتطلبات
Android 8.0+ (API 26)، Android Studio حديث.
